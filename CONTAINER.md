# Rspamd Container

Container images based on [Rspamd](https://rspamd.com/), a fast, free, and open-source spam filtering system.

Sources are available on [GitHub](https://github.com/anthochamp/container-rspamd).

See [README.md](README.md) for full documentation.

## Image tags

- `x.y.z-rspamdA.B.C`: Container image version `x.y.z` with Rspamd `A.B.C`.
- `edge-rspamdA.B.C`: Latest commit build with Rspamd `A.B.C`.

**Tag aliases:**

- `x.y-rspamdA.B.C`: Latest patch of `x.y` with Rspamd `A.B.C`.
- `x-rspamdA.B.C`: Latest minor+patch of `x` with Rspamd `A.B.C`.
- `x.y.z-rspamdA.B`: Version `x.y.z` with latest patch of Rspamd `A.B` (only latest container version updated).
- `x.y-rspamdA.B`: Latest patch of `x.y` with latest patch of Rspamd `A.B`.
- `x-rspamdA.B`: Latest minor+patch of `x` with latest patch of Rspamd `A.B`.
- `x.y.z-rspamdA`: Version `x.y.z` with latest minor+patch of Rspamd `A` (only latest container version updated).
- `x.y-rspamdA`: Latest patch of `x.y` with latest minor+patch of Rspamd `A`.
- `x-rspamdA`: Latest minor+patch of `x` with latest minor+patch of Rspamd `A`.
- `x.y.z`: Version `x.y.z` with latest Rspamd (only latest container version updated).
- `x.y`: Latest patch of `x.y` with latest Rspamd.
- `x`: Latest minor+patch of `x` with latest Rspamd.
- `rspamdA.B.C`: Latest container with Rspamd `A.B.C`.
- `rspamdA.B`: Latest container with latest patch of Rspamd `A.B`.
- `rspamdA`: Latest container with latest minor+patch of Rspamd `A`.
- `latest`: Latest `x.y.z-rspamdA.B.C` tag.
- `edge-rspamdA.B`: Latest commit build with latest patch of Rspamd `A.B`.
- `edge-rspamdA`: Latest commit build with latest minor+patch of Rspamd `A`.
- `edge`: Latest `edge-rspamdA.B.C` tag.
